# Прогнозирование потребительских расходов

Решение команды для второго трека онлайн-конкурса СберИндекса (2026).

## Описание решения

В рамках задачи мы построили пайплайн для прогнозирования трат населения по муниципалитетам и выявления структурных шоков в экономике.

Основные этапы:
1. **Подготовка признаков**. Добавлены лаги (1, 2, 3 месяца) и скользящее среднее. Для учета влияния соседних городов были сформированы пространственные признаки на основе транспортного графа (взвешенные траты 5 ближайших соседей).
2. **Макроэкономика и новости**. В модель добавлена динамика ключевой ставки ЦБ, а также оценка тональности новостного фона.
3. **Моделирование**. В качестве основной модели использован LightGBM. Был применен подход direct forecasting — обучение 4 независимых моделей для горизонтов 1, 3, 6 и 12 месяцев, что позволяет избежать накопления ошибки.
4. **Поиск шоков**. Реализован анализ остатков прогноза модели (ML-Residuals) для выявления аномалий. Этот метод сравнивался с Prophet Changepoints и алгоритмом PELT из библиотеки ruptures.
5. **Сравнение с фундаментальными моделями**. Дополнительно протестирована модель Amazon Chronos в режиме zero-shot.

## Результаты оценки (MAE)

Модель LightGBM показала наименьшую ошибку по сравнению с бейзлайном:

| Модель | 1 мес. | 3 мес. | 6 мес. | 12 мес. |
| :--- | :--- | :--- | :--- | :--- |
| Prophet (бейзлайн СберИндекс) | 1274.71 | 484.46 | 745.41 | 907.07 |
| Chronos (Amazon, zero-shot) | 1791.94 | 2513.96 | 2708.87 | 2694.35 |
| TimesFM (Google, zero-shot) | 1449.81 | 1737.67 | 2052.37 | 2695.83 |
| **LightGBM (наше решение)** | **399.52** | **540.67** | **540.27** | **803.58** |

Фундаментальные модели (TimesFM и Chronos) показали более высокую ошибку, так как при анализе одномерных временных рядов они не имеют возможности учитывать влияние внешних факторов, таких как ставка ЦБ и транспортная доступность, которые критически важны для данной задачи. При этом TimesFM показала себя лучше Chronos на коротких горизонтах.

## Структура репозитория

- `data/` — директория для исходных данных (добавлена в .gitignore из-за ограничений на размер файлов).
- `src/` — исходный код пайплайна.
- `config/` — конфигурационные файлы модели (формат yaml).
- `docs/` — пояснительная записка по методологии.

## Запуск кода

Установка зависимостей:
```bash
pip install -r requirements.txt
```

Исходные файлы датасета (`consumption.parquet`, `connection.parquet` и `market_access.parquet`) необходимо разместить в `data/raw/`.

Последовательность запуска скриптов:
```bash
# 1. Генерация пространственных и временных признаков 
python src/feature_engineering.py

# 2. Добавление новостей
python src/news_integration2.py
python src/news_integration_nlp.py

# 3. Обучение модели и получение прогнозов

#подбор параметров
python src/train_horizons_optimized.py

#без новостей
python src/train_catboost.py
python src/baseline_prophet.py
python src/foundation_models.py
python src/train_horizons_WO_news.py

#с новостями
python src/train_chronos2.py
python src/train_horizons2.py
python src/train_catboost2.py
python src/train_horizons2_W_news.py

# 4. Сравнение методов поиска шоков (Prophet vs Ruptures vs ML-Residuals)
python src/compare_cpd.py

# 5. Оценка дополнительных Foundation Models (Chronos, TimesFM)
python src/foundation_models.py

# 6. Пояснительная записка
docs/МЕТОДОЛОГИЧЕСКИЙ ОТЧЁТ.pdf

# 7. Презентация
docs/Прогнозирование потребительских расходов и обнаружение структурных изменений.pdf
```
